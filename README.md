# Techseeker

Techseeker is a production-grade AI learning platform scaffolded as a Turborepo monorepo.

## Structure

- apps/web: Next.js 15 frontend
- apps/api: FastAPI backend
- packages/ui: shared UI components
- packages/config: shared tooling config
- packages/types: shared TypeScript types

## Getting started

1. Install dependencies with pnpm install
2. Start the workspace with pnpm dev
3. Open http://localhost:3000 for the web app and http://localhost:8000/docs for the API docs
